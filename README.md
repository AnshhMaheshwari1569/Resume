# My Resume – Built with LaTeX

Hey, so I built my resume using LaTeX with the MIT licensed template as the base. I customized it for my own background in AWS, DevOps, and Cybersecurity.

If you want to use it for yourself, it's pretty straightforward.



## How to use this

1. Go to [overleaf.com](https://www.overleaf.com) and make a free account
2. Create a new blank project
3. Paste the `.tex` file from this repo into the editor
4. Swap out my details with yours and hit Recompile
5. Download your PDF and you're good to go

No need to install anything locally, Overleaf handles all of that in the browser.



## Why LaTeX though?

Cause it's ATS friendly which matters a lot when applying to jobs also once you get the hang of the structure it's actually pretty easy to edit. This format doesnt break very easily and looks way more sharp than one made with Canva or similar websites.



Feel free to fork it and use it for your own resume. Hope it helps.
